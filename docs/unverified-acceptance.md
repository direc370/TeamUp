1. **环境**  
   - 确认未把 compose 的端口改成 `0.0.0.0`。  
   - 仅在本机且用户明确要求时再考虑 `docker compose -f server/docker-compose.postgres.yml up`；本次文档任务**禁止启动**。

2. **数据库（P1）**  
   - 若将来启动：用 `pg_isready` / `psql` 连 `127.0.0.1:5432`。  
   - `prisma migrate` 前先备份（见 `data-migration-checklist.md`）。  
   - 验收：表 `profiles` / `projects` / `applications` / `saved_projects` 存在且空库可插入。

3. **鉴权（P5）**  
   - 无 Bearer：`POST /projects`、`PUT /saved-projects/:id`、`PUT /applications/:id`、`GET /user-state` 应 401。  
   - 伪造 JWT 或短于 32 字符的 `AUTH_JWT_SECRET`：应拒绝。  
   - 合法 JWT 的 `sub` 必须成为 `ownerId` / `userId` / `applicantId`，请求体不得改归属。

4. **双账号隔离（P6，尚未执行）**

   - B 不得把 A 的申请改为通过/拒绝（当前也无审批 API）。  
   - B 不得用 A 的 id 写收藏（服务端以 token 为准；Supabase 直连路径依赖 RLS，仓库内**未见**策略文件）。  
   - 用两个浏览器配置文件各登录一次并截图/记日志后，才能勾选「已联调」。
